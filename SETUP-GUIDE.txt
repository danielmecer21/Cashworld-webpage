CASH WORLD WEBSITE - PHP + MYSQL SETUP
=======================================

The website keeps its existing HTML/CSS design. The reviews and contact forms
now use PHP endpoints and a MySQL database on your cPanel hosting.

1. BACK UP FIRST
   In cPanel > File Manager, download a copy of the current public_html folder.

2. CREATE DATABASE
   cPanel > MySQL Databases:
   - Create a database (example: cashworld_site).
   - Create a database user with a strong password.
   - Add that user to the database and grant ALL PRIVILEGES.
   cPanel often prefixes database and user names with your cPanel username.
   Record the exact database name, username and password.

3. IMPORT TABLES
   Open phpMyAdmin, select the new database, choose Import, select database.sql
   from this project, then click Import/Go. You should see reviews and enquiries.

4. CONFIGURE PHP
   In the website's api folder, copy config.example.php to config.php.
   Edit config.php with the exact cPanel database name, database username and
   database password. Set admin_email to your admin email.
   Generate a password hash on a computer with PHP:
     php -r "echo password_hash('Use-A-Long-Unique-Password', PASSWORD_DEFAULT), PHP_EOL;"
   Paste the resulting hash into admin_password_hash. Do not put the plain
   password in that field. Keep config.php private and never commit it to GitHub.

5. UPLOAD TO CPANEL
   Upload the website files into the correct document root (usually public_html).
   Ensure the api folder and its .htaccess file are uploaded. The hosting plan
   must support PHP 8+ and PDO MySQL. Use HTTPS for the live domain.

6. TEST
   Visit yourdomain/reviews.html and submit a test review. It should say it is
   awaiting approval and must NOT appear publicly yet.
   Visit yourdomain/contact.html and submit a test enquiry.
   Visit yourdomain/admin.html and sign in using admin_email and the password
   whose hash you configured. Approve a test review and check the enquiry list.

SECURITY NOTES
- The public API can create reviews/enquiries but cannot list private enquiries.
- Reviews are pending until an administrator publishes them.
- Admin operations require a PHP session; passwords are checked using
  password_verify and the session ID is rotated after login.
- Use a strong unique admin password and keep config.php out of GitHub.
- Collect only details needed to respond. Never ask customers for PINs,
  passwords, card details, transaction reference secrets or identity documents.
- The included honeypot helps deter simple bots; add hosting-level rate limiting
  or CAPTCHA/App Check equivalent if spam becomes an issue.
- Review your privacy policy so it accurately explains what is collected,
  why it is collected, retention and how customers can request deletion.

FILES

api/config.php         create this yourself on cPanel; do not commit
api/db.php             PDO database connection and session helpers
api/reviews.php        public review submit/list endpoint
api/contact.php        public contact enquiry endpoint
api/admin.php          protected admin login and dashboard API
database.sql           MySQL table definitions
